A-CRM 用户使用指南

A-CRM 是面向外贸/自营销售团队的一站式 CRM，覆盖客户管理、商机跟进、订单、邮件、目标绩效、HR 考核与团队协同。

版本：2026-07-16 · 适用对象：业务员、部门负责人、管理员、超级管理员、人事/总经理

1系统简介

登录后，左侧边栏是全部功能入口，按业务分区组织：

分区包含页面谁能看
工作台个人工作首页全员
数据看板外贸销售部数据看板 / 个人数据看板 / 团队看板 / 我的目标CRM 成员
客户客户建档 / 私海客户 / 公海客户CRM 成员
销售流程商机看板 / 商机列表 / 订单管理 / 未关联客户的订单CRM 成员
邮件中心收发邮件 / 邮件模板 / 邮箱账户CRM 成员
销售资料公司资料 / 我的资料CRM 成员
文档中心全公司文档 / 资料板块 / 回收站（超级管理员）全员（板块按部门可见）
组织架构部门与成员 / 成员权限 / 成员邀请（超级管理员、管理员）全员
HR·绩效考核员工档案 / 考核方案 / 考核表 / 员工薪资配置 / 审批人设置按角色可见性设置
协同办公我的审批 / 审批模板全员
团队沟通消息全员
非 CRM 销售人员（如行政、财务）登录后看不到「数据看板 / 客户 / 销售流程 / 邮件中心 / 销售资料」这些销售数据分区，但工作台、文档中心、HR、审批、消息等共享模块照常可用。

2角色与权限

系统角色在「组织架构 → 成员权限」中通过一个下拉统一设置：

角色数据范围能做什么
超级管理员全部数据系统最高权限：全部功能 + 全部模块；唯一可任免超级管理员、管理文档回收站的角色。
管理员全部数据数据范围与超级管理员相同；可管理员工档案、员工薪资配置、成员权限、成员邀请、审批人设置、公海规则与公司资料。不能任免或改动超级管理员，也不能生成超级管理员邀请。
部门负责人本部门（含下级）业务员的全部能力 + 查看团队看板、管理公司资料；给组员的考核表打分。
业务员仅本人管理自己的私海客户、商机、订单、邮件；查看个人看板与「我的目标」；填报自己的考核表。
人事 / 总经理—由超级管理员/管理员在「审批人设置」中指定，负责考核表审批链的第 3、4 步确认（可以不是 CRM 成员）。
在「组织架构 → 部门与成员」把某人设为部门负责人后，其系统角色会自动同步为「部门负责人」；卸任且不再负责任何部门时自动回落为「业务员」。超级管理员/管理员担任部门负责人时角色保持不变。

3工作台全员

登录后的默认首页，汇集与你相关的工作入口和概览。从这里可以快速进入各业务模块。

4数据看板CRM 成员

4.1 外贸销售部数据看板 / 个人数据看板

一屏式经营驾驶舱，顶部可切换公司口径 / 我的口径，以及月 / 季 / 年统计周期（下拉内容随模式变化：月份、Q1–Q4、年份，切换年份会重新取数）。

  • KPI 行：GMV（成交额）、成交订单数、成交客户数、新成交客户数。
  • 商机阶段漏斗：各阶段商机金额柱状图，并显示成交转化率。
  • 本月目标完成率：半圆仪表盘。
  • 订单金额趋势：面积图。
  • 客户来源占比：环形图 + 图例。
  • 业务员成交排行：横向柱状图。
  • 累计概览：历史累计统计。
  • 业务员平均回复时长 / 资料完善度：过程管理指标。

4.2 团队看板

按团队查看本月成交额与新成交客户：团队合计进度条、成交额完成率半圆仪表、组员完成率双列卡片，一眼看清每个组员的达成情况。

5我的目标CRM 成员

个人目标管理页：聚焦月卡片 + 达成半圆仪表 + 12 个月明细表，可在页面上直接设定或修改每月基础目标。

结转规则（自动计算）

  • 未完成结转下月：当月缺口自动加到下月的有效目标里。
  • 超额顺延：当月超出的部分抵扣下月目标。
  • 每季度清零：结转只在季度内滚动，每季度初（1/4/7/10 月）重新开始。
结转是实时计算的，只在「我的目标」页体现；数据看板仍按单月口径统计。明细表中「上月缺口」为紫色、「上月结余」为绿色。

6客户建档CRM 成员

新客户统一从「客户建档」页录入，系统在填写过程中实时查重：

  • 邮箱精确命中：该邮箱已存在客户，直接阻止重复建档。
  • 公司名相似：弹出相似客户提醒，请先确认再继续。

建档成功后客户自动归入你的私海。

7私海 / 公海客户CRM 成员

7.1 列表与筛选

  • 顶部标签切换：全部 / 我的 / 私海 / 公海 / 未分配。
  • 支持客户名搜索、客户分组、产品分组筛选，均可分页。
  • 超级管理员/管理员可按团队 → 业务员逐级筛选。
  • 点「累计成交额」表头可切换倒序 / 正序排序。
  • 每行展示完善度评分、状态、级别、来源、贸易国家/地区等标签。

7.2 认领与转公海

公海客户→ 认领 → 我的私海→ 转公海 → 回到公海
私海有分组上限，达到上限后无法继续认领，请先清理长期未跟进的客户转回公海。

7.3 客户详情面板

点击任意一行，右侧展开详情面板（编辑仍走弹窗），包含五个标签页：

标签页内容
主页分组展示全部客户字段、头像、创建时间；底部有编辑 / 认领 / 转公海按钮。
操作历史审计日志：谁、什么时间、做了什么操作（重新分配、编辑了客户信息等）。
备注该客户的跟进备注。
文件客户相关文件上传 / 下载 / 删除。
电子邮件与该客户的往来邮件。

8商机看板 / 商机列表CRM 成员

商机分四个阶段：待确认需求 → 打样中 → 已成交 / 已流失。

8.1 商机看板（推荐日常使用）

  • 四列 kanban，拖拽卡片即可换阶段。
  • 列头显示该阶段商机数量和总金额（带货币符号）。
  • 卡片展示：阶段色点、商机名、客户、备注、金额与成交概率；点卡片直接编辑。
  • 「+ 新建商机」入口在看板页。
  • 超级管理员/管理员可按团队 → 业务员逐级筛选。

8.2 新建 / 编辑商机

  • 「关联客户」是可搜索下拉，输入客户名即时搜索，只能关联私海客户。
  • 支持多币种金额与成交概率。

8.3 商机列表

表格视角查看全部商机，适合批量核对；支持删除商机。

9订单管理CRM 成员

  • 订单列表支持按状态筛选、分页。
  • 订单会按负责人自动归属对应团队，无需手动填。
  • 侧边栏「未关联客户的订单」视图专门列出还没挂到客户上的订单，便于及时补全归属。
  • 配套能力：商机报价与报价明细（行项目）、产品库（供报价选品）。

10销售目标CRM 成员

按月设定目标成交额和目标新客户数：个人口径是自己的目标，公司口径为全员合计。设定后即驱动数据看板的目标完成率仪表和「我的目标」页。

11邮箱账户与收发邮件CRM 成员

11.1 第一步：配置邮箱账户

每位业务员在「邮箱账户」页配置自己的企业邮箱（SMTP 服务器 + 授权码），配置完成后才能收发邮件。

授权码不是邮箱登录密码，需在企业邮箱后台单独生成（如腾讯企业邮的「客户端专用密码」）。

11.2 收发邮件

  • 「收发邮件」页查看收件与已发邮件；写信走「写邮件」弹窗，支持附件上传。
  • 收件自动入库，并按发件人自动关联到对应客户，同时出现在客户详情的「电子邮件」标签页。
  • 系统会自动过滤通知类域名邮件并去重。

11.3 邮件模板

「邮件模板」页维护常用话术模板（开发信、报价跟进等），写邮件时一键套用。

12销售资料 / 文档中心

两个入口共用同一套文档能力，区别在库和可见范围：

入口库谁能用
销售资料（公司资料 / 我的资料）销售库：产品目录、资质、手册、报价模板等CRM 成员
文档中心（全公司文档 / 资料板块）通用库：全公司共享文档，板块可按部门设置可见范围全员
  • 支持附件上传 / 下载、分类筛选、标题/摘要搜索、分页、在线查看与编辑。

13组织架构与成员权限

13.1 部门与成员全员

查看公司部门（团队）结构和成员归属。业务员通过所属团队参与团队看板统计。

13.2 成员权限超管 / 管理员

  • 系统角色一个下拉管到底：超级管理员 / 管理员 / 部门负责人 / 业务员 / 无（不进入 CRM）。新同事入职后需先赋予角色，才能看到 CRM 销售数据分区并参与考核下发。
  • 模块使用权限：按人勾选可用的业务系统。当前 CRM 可正常开关；ERP、MES 未上线，暂为灰色不可勾选，功能上线后开放。关闭 CRM 后该成员即使有角色也进不了 CRM。
  • 自己那一行不可修改（防自锁）；管理员看不到「超级管理员」选项、也无法改动超级管理员的行（防越权）。

13.3 成员邀请超管 / 管理员

生成带预设角色、模块权限、部门与有效期的邀请链接，新成员打开链接填写姓名邮箱密码即可加入，无需邮箱验证。管理员不能生成「超级管理员」邀请。

14HR · 绩效考核

月度绩效闭环：制方案 → 下发 → 员工填报 → 主管打分 → 人事确认 → 总经理确认 → 核算绩效薪资。

① 考核方案（HR/管理员）→ ② 下发给员工→ ③ 员工填报 + 签名→ ④ 主管打分 + 签名→ ⑤ 人事确认→ ⑥ 总经理确认 · 归档

14.1 员工档案（员工主数据）超管 / 管理员

  • 全公司员工主数据表，按在职 / 试用 / 离职分组页签管理，支持按姓名 / 工号 / 手机号搜索。
  • 建档表单共六个板块：基本身份信息（工号唯一、姓名、性别、身份证号、出生日期、籍贯、证件照、入职资料附件）、岗位与组织信息（所属部门、关联系统账号、岗位、工作地点）、在职状态与关键日期（状态、入职/转正日期、试用期、工龄自动计算、合同起止与类型）、薪酬与发薪（薪资结构、银行卡、开户行）、联系方式、离职信息（离职时填：离职日期、类型主动/被动、原因、离职资料附件）。
  • 关联系统账号：把档案和登录账号绑定，是离职交接的前提，建议建档时就选好。
离职交接：把员工状态改为「离职」并保存时，系统自动执行交接——名下客户与商机按你的选择退回公海（默认，新人从公海认领）或转移给指定接手人；其个人文档进入文档回收站；该账号 CRM 角色置为「无」。新员工请走「成员邀请」开新账号，不要复用离职账号。

14.2 考核方案

  • 每月一套可编辑方案：方案名称、考核月份、及格分、单项计分上限。
  • 考核指标：指标名、维度（业绩结果 / 客户开发 / 系统规范 / 过程效率）、考核标准、权重、底线值、目标值；数据来源可选 CRM·业绩额 / CRM·新客户 / 手动填报 / 主管判定。
  • 发放系数档：按总分区间定发放系数（也可按得分比例）。
  • 编辑器还包含「月度数据统计」参考区（询盘数、成交客户、复购、新客户等，部分自动取自 CRM）和「评分与绩效发放规则」「考核结果应用」说明区。
  • 方案保存后点「下发给员工」，为选中的业务员各生成一张本月考核表；已下发的自动跳过，不会重复。

14.3 考核表（四步审批）

状态当前步骤由谁操作
待填报填写各指标「完成值」，提交并电子签名被考核员工
待打分为各指标「得分」，打分并签名主管
待人事确认人事确认 + 签指定的人事
待总经理确认总经理确认 + 签，签完归档指定的总经理
已归档流程结束，可查阅—

考核表底部自动核算绩效薪资：绩效基数 × 发放系数 = 本月实发绩效。

每一步都可上传电子签名图片；不上传也可继续，系统会再确认一次。

14.4 员工薪资配置超管 / 管理员

HR 维护每位业务员的月薪总额、绩效占比、月度业绩底线与职级备注，是绩效基数的数据来源。

14.5 审批人设置超管 / 管理员

  • 指定谁担任人事与总经理（即审批链第 3、4 步的确认人）。
  • 板块可见性：按角色（业务员 / 主管 / 管理员）勾选可见的 HR 子模块。管理员始终全可见；被指定的人事/总经理始终能看到考核表。
如果取消「业务员 · 考核表」的可见性，业务员将看不到自己的考核表，无法自填与签名——请谨慎操作。

15协同办公（审批）全员

  • 我的审批：发起审批、处理待我审批的单据、查看我发起/已办的记录。
  • 审批模板：仅超级管理员与行政部门成员可见并维护请假、报销等审批单模板；其他成员看不到该入口，但发起审批照常使用模板。

16团队沟通全员

内置「消息」模块，团队成员即时沟通（单聊 / 群聊），支持发送文件附件、群消息已读名单。群聊规则像微信：

  • 建群必须填写群公告；群主更新公告会自动以「【群公告】」消息推送到群里。
  • 群主（建群人）可编辑群名/公告、移除成员、转让群主（在群聊详情的成员列表操作，转让后自己变普通成员，群里会推送变更消息）。
  • 所有成员可退出群聊；群里还有其他人时，群主必须先转让群主才能退群。

17常见问题 FAQ

Q：为什么我看不到「数据看板 / 客户」这些菜单？

你的账号还没有被赋予 CRM 角色，或 CRM 模块开关被关闭。请联系超级管理员/管理员在「组织架构 → 成员权限」为你分配角色并开启 CRM 模块。

Q：认领公海客户时提示失败？

大概率是私海数量达到了分组上限。先把长期没跟进的客户「转公海」，再认领新客户。

Q：发邮件失败 / 收不到客户邮件？

检查「邮箱账户」里的 SMTP 配置与授权码是否有效（授权码过期需在企业邮箱后台重新生成）。收件有几分钟的同步间隔，属正常现象。

Q：新建商机时搜不到客户？

关联客户下拉只显示你私海里的客户。客户在公海时请先认领。

Q：下发考核方案时提示「暂无 CRM 销售成员」？

请先在「成员权限」为相关同事赋予 CRM 角色，再回到考核方案页下发。

Q：我的目标里「有效目标」为什么和我设的不一样？

有效目标 = 基础目标 + 上月结转（缺口为加、结余为减），结转在每季度初清零。详见第 5 节。

Q：页面改动后看不到最新效果？

浏览器硬刷新：Mac 按 Cmd + Shift + R，Windows 按 Ctrl + Shift + R。
