A-CRM 用户使用指南

面向外贸/自营销售团队的一站式 CRM——客户、商机、订单、邮件、目标绩效、HR 考核与团队协同，全部在一个系统里完成。

版本 2026-07 适用：业务员 · 主管 · 管理员 · 人事/总经理 建议浏览器：Chrome / Edge / Safari

🚀按角色快速上手

不想读全文？找到你的角色，把下面几步跑通就能开始工作。

🧑‍💼 业务员 · 第一天

  1. 找管理员在「成员权限」给你分配 CRM 角色
  2. 去「邮箱账户」配置企业邮箱（SMTP + 授权码）
  3. 在「我的目标」设定本月基础目标
  4. 去「公海客户」认领客户，或「客户建档」录入新客户
  5. 为客户创建商机，日常在「商机看板」拖动推进

👔 主管 · 日常三件事

  1. 早上看「团队看板」：组员完成率一屏尽览
  2. 盯「商机看板」按团队筛选，推进卡在打样的单子
  3. 月底在「考核表」给组员打分并签名

🛠 管理员 · 初始化清单

  1. 「组织架构 → 部门与成员」建团队、归属成员
  2. 「成员权限」为每人分配业务员/主管角色
  3. 「审批人设置」指定人事与总经理、配置板块可见性
  4. 「员工薪资配置」录入月薪/绩效占比/业绩底线
  5. 「销售目标」设定公司与个人月度目标

📋 人事 / 总经理 · 每月月初

  1. HR：在「考核方案」建本月方案并「下发给员工」
  2. 等员工填报、主管打分完成后，人事做第 3 步确认
  3. 总经理做第 4 步确认，考核表归档
  4. 「实发绩效」自动核算，作为发薪依据

2角色与权限

角色能做什么
业务员管理自己的私海客户、商机、订单、邮件；查看个人看板与「我的目标」；填报自己的考核表。
主管业务员的全部能力 + 查看团队看板；给组员的考核表打分。
管理员全部数据可见；看板可按「团队 → 业务员」逐级筛选；管理成员权限、员工薪资配置、绩效审批人设置。
人事 / 总经理由管理员在「审批人设置」中指定，负责考核表审批链的第 3、4 步确认。

3数据看板CRM 成员

3.1 外贸销售部数据看板 / 个人数据看板

侧边栏 → 数据看板 → 外贸销售部数据看板 / 个人数据看板

一屏式经营驾驶舱。顶部可切换公司口径 / 我的口径，以及月 / 季 / 年统计周期（下拉内容随模式变化：月份、Q1–Q4、年份，切换年份会重新取数）。

  • KPI 行：GMV（成交额）、成交订单数、成交客户数、新成交客户数。
  • 商机阶段漏斗：各阶段商机金额柱状图 + 成交转化率。
  • 本月目标完成率：半圆仪表盘。
  • 订单金额趋势：面积图，看业绩走势。
  • 客户来源占比：环形图 + 图例，看渠道结构。
  • 业务员成交排行：横向柱状图。
  • 累计概览：历史累计统计。
  • 平均回复时长 / 资料完善度：过程管理指标，督促及时回复与资料补全。

3.2 团队看板

侧边栏 → 数据看板 → 团队看板

按团队查看本月成交额与新成交客户：团队合计进度条、成交额完成率半圆仪表、组员完成率双列卡片，一眼看清每个组员的达成情况。

4我的目标CRM 成员

侧边栏 → 数据看板 → 我的目标

个人目标管理页：聚焦月卡片 + 达成半圆仪表 + 12 个月明细表，可在页面上直接设定或修改每月基础目标。

结转规则（系统自动计算）

规则含义例子（目标 10 万/月）
未完成结转下月当月缺口加到下月有效目标1 月做了 8 万 → 2 月有效目标 12 万
超额顺延当月超出部分抵扣下月目标1 月做了 13 万 → 2 月有效目标 7 万
每季度清零结转只在季度内滚动4 月（新季度）重新从基础目标 10 万开始
结转实时计算，只在「我的目标」页体现；数据看板仍按单月口径统计。明细表中「上月缺口」为紫色、「上月结余」为绿色。

5客户建档CRM 成员

侧边栏 → 客户 → 客户建档

新客户统一从「客户建档」页录入，系统在填写过程中实时查重：

  • 邮箱精确命中：该邮箱已存在客户，直接阻止重复建档，避免撞单。
  • 公司名相似：弹出相似客户提醒，请先确认再继续。

建档成功后客户自动归入你的私海。

6私海 / 公海客户CRM 成员

侧边栏 → 客户 → 私海客户 / 公海客户

6.1 列表与筛选

  • 顶部标签切换：全部 / 我的 / 私海 / 公海 / 未分配。
  • 支持客户名搜索、客户分组、产品分组筛选，均可分页。
  • 管理员可按团队 → 业务员逐级筛选。
  • 点「累计成交额」表头可切换倒序 / 正序。
  • 每行展示完善度评分、状态、级别、来源、贸易国家/地区等标签。

6.2 认领与转公海

公海客户→ 认领 → 我的私海→ 转公海 → 回到公海
私海有分组数量上限，达到上限后无法继续认领。请定期把长期未跟进的客户转回公海，把私海名额留给活跃客户。

6.3 客户详情面板

点击任意一行，右侧展开详情面板（编辑走弹窗），包含五个标签页：

标签页内容
主页分组展示全部客户字段、头像、创建时间；底部有编辑 / 认领 / 转公海按钮。
操作历史审计日志：谁、什么时间、做了什么（重新分配、编辑了客户信息等），责任可追溯。
备注该客户的跟进备注。
文件客户相关文件上传 / 下载 / 删除。
电子邮件与该客户的往来邮件（自动关联）。

7商机看板 / 商机列表CRM 成员

侧边栏 → 销售流程 → 商机看板 / 商机列表

商机分四个阶段：

待确认需求→ 打样中→ 已成交 ✓/ 已流失 ✗

7.1 商机看板（推荐日常使用）

  • 四列 kanban，拖拽卡片即可换阶段，跟进状态随手更新。
  • 列头显示该阶段商机数量和总金额（带货币符号）。
  • 卡片展示：阶段色点、商机名、客户、备注、金额与成交概率；点卡片直接编辑。
  • 「+ 新建商机」入口在看板页；管理员可按团队 → 业务员逐级筛选。

7.2 新建 / 编辑商机

  • 「关联客户」是可搜索下拉，输入客户名即时搜索，只能关联你私海的客户。
  • 支持多币种金额与成交概率。

7.3 商机列表

表格视角查看全部商机，适合批量核对，支持删除商机。

8订单管理CRM 成员

侧边栏 → 销售流程 → 订单管理 / 未关联客户的订单

  • 订单列表支持按状态筛选、分页。
  • 订单按负责人自动归属对应团队，无需手动填。
  • 「未关联客户的订单」专门列出还没挂到客户上的订单——请及时补全归属，否则该订单不计入客户累计成交额。
  • 配套能力：商机报价与报价明细（行项目）、产品库（供报价选品）。

9销售目标CRM 成员

按月设定目标成交额和目标新客户数：个人口径是自己的目标，公司口径为全员合计。设定后即驱动数据看板的目标完成率仪表和「我的目标」页。

10邮箱账户与收发邮件CRM 成员

侧边栏 → 邮件中心 → 邮箱账户 / 收发邮件 / 邮件模板

10.1 第一步：配置邮箱账户

每位业务员先在「邮箱账户」配置自己的企业邮箱（SMTP 服务器 + 授权码），配置完成后才能收发邮件。

授权码不是邮箱登录密码，需要在企业邮箱后台单独生成（如腾讯企业邮的「客户端专用密码」）。授权码会过期，发信失败时优先检查这里。

10.2 收发邮件

  • 「收发邮件」页查看收件与已发邮件；写信走「写邮件」弹窗，支持附件上传。
  • 收件自动入库，并按发件人自动关联到对应客户，同时出现在客户详情的「电子邮件」标签页。
  • 系统自动过滤通知类域名邮件并去重，收件箱只留真实客户往来。

10.3 邮件模板

维护常用话术模板（开发信、报价跟进、催款等），写邮件时一键套用，保持团队话术统一。

11销售资料 / 文档中心

两个入口共用同一套文档能力，区别在库和可见范围：

入口库谁能用
销售资料（公司资料 / 我的资料）销售库：产品目录、资质、手册、报价模板等CRM 成员
文档中心（全公司文档 / 我的文档）通用库：全公司共享文档全员

支持附件上传 / 下载、分类筛选、标题/摘要搜索、分页、在线查看与编辑。

12组织架构与成员权限

12.1 部门与成员全员

查看公司部门（团队）结构和成员归属。业务员通过所属团队参与团队看板统计。

12.2 成员权限仅管理员

管理员在此为成员分配 CRM 角色（业务员 / 主管），决定其能否看到 CRM 销售数据分区。

新同事入职流程：先在「部门与成员」归到团队 → 再到「成员权限」赋予角色 → 之后才能参与考核下发、团队统计等流程。

13HR · 绩效考核

月度绩效闭环，六步走完：

① 制定考核方案→ ② 下发给员工→ ③ 员工填报＋签→ ④ 主管打分＋签→ ⑤ 人事确认→ ⑥ 总经理确认 · 归档

13.1 考核方案

侧边栏 → HR·绩效考核 → 考核方案

  • 每月一套可编辑方案：方案名称、考核月份、及格分、单项计分上限。
  • 考核指标：指标名、维度（业绩结果 / 客户开发 / 系统规范 / 过程效率）、考核标准、权重、底线值、目标值；数据来源可选 CRM·业绩额 / CRM·新客户 / 手动填报 / 主管判定——CRM 来源的指标完成值自动取数，不用手填。
  • 发放系数档：按总分区间定发放系数，也可设「按得分比例」。
  • 编辑器含「月度数据统计」参考区（询盘数、成交客户、复购、新客户等）和「评分与绩效发放规则」「考核结果应用」说明区。
  • 方案保存后点「下发给员工」，为选中业务员各生成一张本月考核表；已下发的自动跳过，不会重复生成。

13.2 考核表（四步电子签审批）

侧边栏 → HR·绩效考核 → 考核表

状态当前步骤由谁操作
待填报填写各指标「完成值」，提交并电子签名被考核员工
待打分为各指标「得分」，打分并签名主管
待人事确认人事确认 + 签指定的人事
待总经理确认总经理确认 + 签，签完归档指定的总经理
已归档流程结束，可随时查阅—

考核表底部自动核算绩效薪资：绩效基数 × 发放系数 = 本月实发绩效。

每一步都可上传电子签名图片；不上传也可以继续，系统会再确认一次。

13.3 员工薪资配置仅管理员

HR 维护每位业务员的月薪总额、绩效占比、月度业绩底线与职级备注——绩效基数即由此而来（月薪 × 绩效占比）。

13.4 审批人设置仅管理员

  • 指定谁担任人事与总经理（审批链第 3、4 步确认人）。
  • 板块可见性：按角色（业务员 / 主管 / 管理员）勾选可见的 HR 子模块。管理员始终全可见；被指定的人事/总经理始终能看到考核表。
如果取消「业务员 · 考核表」的可见性，业务员将看不到自己的考核表，无法自填与签名——请谨慎操作。

14协同办公（审批）全员

  • 我的审批：发起审批、处理待我审批的单据、查看我发起/已办的记录。
  • 审批模板：管理员维护请假、报销等审批单模板，规范填写字段与审批流。

15团队沟通全员

内置「消息」模块，团队成员即时沟通，支持发送文件附件，报价单、图片随聊随传。

17名词解释

名词含义
私海归属于某个业务员的客户，只有归属人（和管理员）可跟进。
公海无归属的共享客户池，任何业务员都可以「认领」进自己私海。
认领 / 转公海把公海客户捞进私海 / 把私海客户放回公海。
GMV（成交额）统计周期内已成交订单的总金额。
基础目标 / 有效目标基础目标是你设定的数；有效目标 = 基础目标 + 上月结转（缺口加、结余减）。
结转上月缺口或结余滚入本月，季度内滚动、季度初清零。
完善度客户资料填写完整程度的评分，看板上有全员对比。
绩效基数月薪总额 × 绩效占比，即当月可发绩效的满额。
发放系数由考核总分落入的分数档决定；实发绩效 = 绩效基数 × 发放系数。

18常见问题 FAQ

为什么我看不到「数据看板 / 客户」这些菜单？
你的账号还没有被赋予 CRM 角色。请联系管理员在「组织架构 → 成员权限」为你分配业务员或主管角色。
认领公海客户时提示失败？
大概率是私海数量达到了分组上限。先把长期没跟进的客户「转公海」，再认领新客户。
发邮件失败 / 收不到客户邮件？
检查「邮箱账户」里的 SMTP 配置与授权码是否有效（授权码过期需在企业邮箱后台重新生成）。收件有几分钟同步间隔，属正常现象。
新建商机时搜不到客户？
关联客户下拉只显示你私海里的客户。客户在公海时请先认领。
下发考核方案时提示「暂无 CRM 销售成员」？
请先在「成员权限」为相关同事赋予 CRM 角色，再回到考核方案页下发。
「我的目标」里有效目标和我设的不一样？
有效目标 = 基础目标 + 上月结转（缺口为加、结余为减），结转在每季度初清零。详见第 4 节。
订单为什么没算进客户的累计成交额？
