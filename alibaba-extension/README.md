# wintouchspace 建档助手（Chrome 插件）

在阿里国际站后台的页面上，就地告诉业务员「这个买家有没有被同事建过档」，并一键建档到 wintouchspace CRM。

## 它解决什么

公司有四五个阿里店铺，不同业务员会碰到同一个买家。阿里把买家邮箱藏了，CRM 里靠邮箱/电话查重就失效——
生产库里有 1978 个客户邮箱、电话、WhatsApp 三样全空，撞单完全看不出来。

买家的**会员 ID**（形如 `120613876220`）才是稳定可拿到的唯一身份，所以拿它当阿里来源客户的钥匙。
它在页面上有三个出处，按可靠度依次找：

1. 买家没填公司名时，阿里用 `NoCompanyName_120613876220` 当占位公司名，ID 就在里面
2. 「Ta的Alibaba买家主页」等链接的 `memberId=` 参数
3. 当前页面 URL 的同名参数

老式页面上的 loginId（`cn1234567890` 这种）也仍然认。

- 建档时写进 `crm_customers.alibaba_account`
- 查重多一个维度，大小写不敏感、全库比对（跨负责人，不按辖区收口）
- 插件在阿里页面上就地提示，**建之前**就知道撞没撞，而不是建完才发现

## 安装

1. 打开 `chrome://extensions`，右上角开「开发者模式」
2. 点「加载已解压的扩展程序」，选这个 `alibaba-extension` 目录
3. 点插件图标打开设置，填：
   - CRM 地址：`https://wintouchspace.com`
   - 个人访问令牌：wintouchspace →「个人设置 → 访问令牌」里复制
4. 点「保存并验证」，显示「已连接：你的名字」就好了

账户 ID 和本人身份是用令牌自动探出来的，不用填。

## 用法

在阿里后台任意页面（询盘详情、订单、买家资料）右下角会出现一个黄色的「建档」按钮。点开后：

- 自动认出**阿里买家账号 / 公司名称 / 联系人 / 国家**，并立刻查重
  - 🟢 全公司都还没建过 → 可以建
  - 🔴 已被某某建档 → 就地显示是谁、哪天建的、客户编号
  - 🟡 公司名相近的已有几个 → 列出来让你确认是不是同一家
- 认得不准就手动改，或点字段旁的「**从页面取**」，再去点页面上那段文字——
  插件会记住这类页面的取值位置，之后自动填。阿里改版了就重新点一次。
- 「建档到 wintouchspace」提交，客户自动归到你名下，来源标记为 ALIBABA

**关于邮箱**：阿里没在页面上显示的邮箱，插件拿不到，这里会是空的。先建档即可——
之后阿里的询盘通知邮件进了 CRM 邮件中心，会按客户自动归档补上联系人。

## 实现上的三个点

- **网络请求全部走 background service worker**。content script 直接 fetch 会被阿里页面的 CORS 挡掉；
  service worker 拿着 `host_permissions` 发的请求不受页面同源策略约束。令牌也只存在这一侧，不进阿里页面的 JS 上下文。
- **请求头必须用连字符** `api-access-token`。生产 nginx 会丢掉带下划线的头，
  `api_access_token` 经 nginx 恒返 401（实测过：连字符 200 / 下划线 401）。
- **面板整个放在 shadow DOM 里**，跟阿里自己的样式互不干扰。
- **不写死任何选择器**。阿里的后台 DOM 我们控制不了也会变，所以只有正则启发式 + 用户点一次学到的选择器。

## 文件

| 文件 | 干什么 |
|---|---|
| `manifest.json` | MV3 清单，只在 `*.alibaba.com` 上注入 |
| `background.js` | 所有 API 调用、令牌保管、账户自动探测 |
| `extract.js` | 页面取值：学到的选择器优先，正则启发式兜底 |
| `countries.js` | 页面上的国家写法 → CRM 的国家枚举，认不出就留空 |
| `content.js` | 浮窗面板：查重提示、字段编辑、「从页面取」、提交建档 |
| `options.html/js` | 设置页：填地址和令牌并验证 |

## 用到的接口

| 接口 | 用途 |
|---|---|
| `GET /api/v1/profile` | 验令牌，顺带探出账户 ID 和本人 ID |
| `GET /api/v1/accounts/:id/crm/customers/check_duplicate` | 查重，参数 `alibaba_account` / `email` / `name` |
| `POST /api/v1/accounts/:id/crm/customers` | 建档 |
